# PETFORM interactive prototype

A browser demo for the Interaction Prototype Design course submission.

## Preview

After GitHub Pages is enabled: https://p3tform.github.io/petform-demo/

Recommended: a desktop browser. No sign-in is required.

## Try it

1. Open Character and explore the sample character or import an image.
2. Open Animations to preview and edit frames.
3. Open Playground to try interactions.
4. Save locally or download a JSON project backup / sprite PNG.

## Demo scope

AI generation is simulated. This static demo does not connect to live AI services or build Windows executables. Projects stay in the current browser. The complete local application and desktop export are demonstrated separately in the submission video.

## Source and publishing

This repository contains the editable source of the static interactive demo. Keep all files together. GitHub Pages can publish the main branch from / (root); no build command is needed. The .nojekyll file disables Jekyll processing.
